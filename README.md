# 📋 Интерактивный справочник ПП 1875 для ОКПД2

Мгновенная проверка кодов ОКПД2 на действие национального режима при осуществлении закупок по 44-ФЗ и 223-ФЗ. Без без регистрации, без установки.

🌐 **Открыть справочник:** [https://prog815.github.io/okpd2-pp1875/](https://prog815.github.io/okpd2-pp1875/)

---

Коллеги, этот справочник создан для тех, кто ежедневно работает с государственными и муниципальными закупками: специалистов по закупкам, контрактных управляющих, поставщиков, юристов и бухгалтеров. Главная задача — помочь за секунды определить, подпадает ли конкретный код ОКПД2 под действие Постановления Правительства РФ от 23.12.2024 № 1875.

## 🎯 Что это и для кого

**ПП 1875** — единый документ национального режима для 44-ФЗ и 223-ФЗ. Он устанавливает три меры регулирования, которые в справочнике обозначены как приложения:
- **Приложение 1 (Запрет)** — запрет допуска иностранных товаров.
- **Приложение 2 (Ограничение)** — ограничение допуска иностранных товаров.
- **Приложение 3 (Преимущество)** — преимущество для российских товаров и минимальная доля закупок (квота в процентах).

Справочник пригодится, если вам нужно:
- быстро определить статус товара перед публикацией извещения в ЕИС;
- проверить, действует ли запрет или ограничение на закупаемую продукцию;
- узнать минимальную долю (квоту) для товаров из Приложения 3;
- найти все коды с нацрежимом по конкретному слову в названии.

## ⚡ Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются во время ввода — без кнопки «Найти».
- **Поиск по коду — строго с начала кода.** Запросы `08.12`, `08.12.12.140` показывают нужную ветвь классификатора. Точки можно не ставить.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `медицинская повязка` найдёт записи, где есть оба слова.
- **Фильтр по нацрежиму.** Выпадающий список с тремя вариантами: `Любой` / `С нацрежимом` / `Без нацрежима`. Позволяет отсеять всё лишнее.
- **Фильтр «Только коды нижнего уровня».** Оставляет только конкретные виды продукции, которые используются в закупках.
- **Кликабельные бейджи.** Клик по бейджу `Прил.1`, `Прил.2` или `Прил.3` покажет все коды этого приложения (URL сохраняется, можно делиться). Клик по бейджу `без нацрежима` — покажет только коды, не подпадающие под ПП 1875.
- **Карточки вместо таблицы.** Каждая запись — отдельная карточка: код, статус уровня (нижний или группировка), наименование, цветные бейджи приложений.
- **Копирование кода в один клик.** Клик по коду — и он в буфере обмена.
- **Копирование строки.** Кнопка `📋 строка` копирует пару «код; название» вместе со статусами для вставки в таблицу или письмо.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере.
- **Прямые ссылки на коды.** Каждый код можно передать коллеге через `?code=…` в адресе, а фильтр по приложению — через `?app=…`.

## 🧭 Как пользоваться

1. **Введите код или название** в строку поиска.
2. **Выберите фильтр по нацрежиму**, если нужно видеть только ограничения или только свободные для закупки коды.
3. **Включите галочку «Только коды нижнего уровня»**, если ищете конкретный код для закупки.
4. **Кликните по коду** в карточке — он скопируется.
5. **Нажмите `📋 строка`**, чтобы скопировать код с названием и статусами.
6. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
7. **Нажмите на цветной бейдж** (`Прил.1`, `Прил.2` или `Прил.3`), чтобы отфильтровать весь список по этому приложению.

## ❓ FAQ

**Чем этот справочник отличается от обычного ОКПД2?**
Обычный ОКПД2 показывает только коды и названия продукции. Наш справочник — это тот же ОКПД2, но к каждому коду добавлены статусы: подпадает ли товар под Запрет, Ограничение или Преимущество по ПП 1875.

**Что означают приложения 1, 2 и 3?**
Это три меры национального режима:
- **Прил. 1 (Запрет)** — иностранный товар закупать нельзя (за редкими исключениями).
- **Прил. 2 (Ограничение)** — иностранный товар можно закупать, но с ограничениями (например, «второй лишний»).
- **Прил. 3 (Преимущество)** — российский товар имеет преимущество в цене, а также устанавливается минимальная доля (квота) его закупки.

**Что значит квота (X%) в бейдже Прил.3?**
Это минимальная доля закупок российских товаров, которую заказчик обязан обеспечить. Например, бейдж `Прил.3 п.1 (80%)` означает, что не менее 80% закупок по этому коду должны быть российского происхождения.

**Почему у одного кода может быть несколько бейджей?**
Законодательство предусматривает разные меры для разных случаев. Один и тот же товар может одновременно подпадать под Ограничение (Прил. 2) и Преимущество (Прил. 3). Справочник показывает все применимые меры.

**Что означает бейдж «без нацрежима»?**
Это значит, что код не входит ни в одно из трёх приложений ПП 1875. На закупку такого товара национальный режим не распространяется. Клик по этому бейджу покажет все такие коды.

**Как найти код для закупки по 44-ФЗ?**
Введите ключевое слово из названия товара, выберите фильтр `С нацрежимом` и включите галочку «Только коды нижнего уровня». Вы увидите конкретные коды, для которых действуют ограничения.

**Справочник заменяет консультацию юриста?**
Нет. Справочник — инструмент предварительной проверки. Для принятия юридически значимых решений обращайтесь к официальным источникам и специалистам по госзакупкам.
