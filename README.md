# 📋 Интерактивный справочник ПП 1875 для ОКПД2

Онлайн-справочник для проверки кодов ОКПД2 на действие национального режима при осуществлении закупок по 44-ФЗ и 223-ФЗ. Справочник создан на основе официального машиночитаемого снимка ОКПД2 и перечней Постановления Правительства РФ от 23.12.2024 № 1875.

## Что кодирует ПП 1875 и на какой вопрос отвечает

**ПП 1875** — единый документ национального режима для 44-ФЗ и 223-ФЗ. Он устанавливает три меры регулирования, которые в справочнике обозначены как приложения:
- **Приложение 1 (Запрет)** — запрет допуска иностранных товаров.
- **Приложение 2 (Ограничение)** — ограничение допуска иностранных товаров.
- **Приложение 3 (Преимущество)** — преимущество для российских товаров и минимальная доля закупок (квота в процентах).

Справочник содержит **весь** перечень ОКПД2 (порядка 21 000 записей) и добавляет к каждой записи информацию о том, подпадает ли она под действие постановления. Главная задача — помочь за секунды определить, можно ли закупать иностранный товар по конкретному коду или какие ограничения действуют.

> **Не путать с соседями.** ОКПД2 — это полный классификатор продукции (отвечает на вопрос «что производится или закупается»). ПП 1875 — это надстройка над ним, которая фильтрует те же коды по наличию национального режима. Если вам нужен код продукции без привязки к закупочным ограничениям, используйте [базовый справочник ОКПД2](https://prog815.github.io/okpd2/). Если нужен код вида деятельности компании — используйте [ОКВЭД2](https://prog815.github.io/okved2/).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти».
- **Поиск по коду — строго с начала кода.** Запросы `08.12`, `08.12.12.140` показывают нужную ветвь классификатора. Точки можно не ставить.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `медицинская повязка` найдёт записи, где есть оба слова.
- **Фильтр по нацрежиму.** Выпадающий список с тремя вариантами: `Любой` / `С нацрежимом` / `Без нацрежима`.
- **Фильтр «Только коды нижнего уровня».** Оставляет только конкретные виды продукции, которые используются в закупках.
- **Кликабельные бейджи.** Клик по бейджу `Прил.1`, `Прил.2` или `Прил.3` покажет все коды этого приложения (URL сохраняется, можно делиться). Клик по бейджу `без нацрежима` — покажет только коды, не подпадающие под ПП 1875.
- **Копирование кода в один клик.** Клик по коду — и он в буфере обмена.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` формирует подробную карточку со ссылкой, кодом, статусами и датой.
- **Прямые ссылки.** Каждый код можно передать через `?code=…` в адресе, а фильтр по приложению — через `?app=…`.

## Примеры запросов

- `08.12.12.140` — Щебень. Ограничение (п. 1 Прил. 2) + Преимущество (п. 1 Прил. 3, квота 80%).
- `13.96.17` — Ткани узкие. Покажет статусы для этой группы.
- `медицинская повязка` — найдёт коды, где встречаются оба слова, с указанием применимых мер.
- `Нацрежим: С нацрежимом` + галочка «Только коды нижнего уровня» — покажет все конкретные коды, которые подпадают под действие ПП 1875.

**Популярные коды:**
- `08.12.12.140` — Щебень;
- `26.20.11.190` — Компьютеры портативные (ноутбуки);
- `32.50.13.190` — Шприцы;
- `10.51.11.110` — Молоко жидкое обработанное.
