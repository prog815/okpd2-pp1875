# Справочник ПП 1875 для ОКПД2

Быстрый, бесплатный и актуальный онлайн-справочник для проверки кодов ОКПД2 на действие национального режима в закупках по 44-ФЗ и 223-ФЗ.

🌐 **Сайт:** https://prog815.github.io/okpd2-pp1875/

Мгновенно показывает, подпадает ли любой код ОКПД2 под действие Постановления Правительства РФ № 1875: **Запрет** (Приложение 1), **Ограничение** (Приложение 2) или **Преимущество** (Приложение 3).

## 🎯 Для кого этот справочник

Для специалистов по госзакупкам, контрактных управляющих, участников торгов и бухгалтеров, которым нужно быстро определить:

- Можно ли закупать иностранный товар по данному коду ОКПД2
- Какие ограничения допуска иностранной продукции действуют
- Какая минимальная доля российских товаров обязательна (для Приложения 3)

Справочник заменяет долгий ручной поиск по тексту постановления в правовых системах: ввели код — сразу видите статус.

## ✨ Как пользоваться

1. **Введите код ОКПД2** в поисковую строку — например, `08.12.12.140` (Щебень).
2. **Или введите название товара** — например, `медицинская` или `текстильные ткани`.
3. **При необходимости включите фильтры:**
   - «Только коды нижнего уровня» — скрыть промежуточные группировки, оставить только коды, которые используются в закупках
   - «Только с нацрежимом» — показать только коды, попадающие под действие ПП 1875

### Примеры запросов

| Запрос | Что покажет |
|---|---|
| `08.12.12.140` | Щебень — Ограничение (п. 1 Прил. 2) + Преимущество (п. 1 Прил. 3, квота 80%) |
| `13.96.17` | Ткани узкие — все коды группы со статусами |
| `медицинская повязка` | Несколько кодов с указанием, какие попадают под Запрет/Ограничение |
| Включить фильтр «Только с нацрежимом» | Все ~6 900 кодов, к которым применяются меры нацрежима |

## 🧩 Что видно в таблице результатов

Для каждого кода ОКПД2 справочник показывает:

- **Код и наименование** — с возможностью скопировать код в один клик (иконка 📋) и перейти к поиску в ГАРАНТе (иконка 🏛️)
- **Уровень** — помечаются коды нижнего уровня (зелёный бейдж «✓ нижний»), которые используются в закупках
- **Статусы по трём приложениям:**
  - `п.N` — номер позиции в приложении (наведение показывает полное наименование позиции)
  - `п.N (X%)` — для Приложения 3 дополнительно показана минимальная доля российских товаров
  - Клик по бейджу статуса открывает полный текст постановления в ГАРАНТе

## ❓ Частые вопросы

**Где навигационное меню для перехода к другим справочникам?**
Прокрутите страницу вниз — меню находится в самом низу.

**Что означает «код нижнего уровня»?**
Это код ОКПД2, который не имеет дочерних позиций — именно такие коды указываются в закупочной документации в ЕИС. Промежуточные группировки (классы, подклассы, группы) используются только для структуры классификатора.

**Почему у одного кода одновременно отображаются статусы из нескольких приложений?**
Постановление ПП 1875 предусматривает разные меры регулирования, и один и тот же товар может одновременно попадать, например, под Ограничение (Прил. 2) и Преимущество (Прил. 3) — это нормальная ситуация, определённая законодателем.

**Справочник заменяет консультацию юриста?**
Нет. Справочник — инструмент предварительной проверки. Для принятия юридически значимых решений обращайтесь к официальным источникам и специалистам по госзакупкам.
