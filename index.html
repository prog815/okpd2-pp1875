📋 Справочник ПП 1875 для ОКПД2

Проверка кодов ОКПД2 на действие национального режима при осуществлении закупок по 44-ФЗ и 223-ФЗ. Мгновенно показывает, подпадает ли код под действие Постановления Правительства РФ № 1875: Запрет (Прил. 1), Ограничение (Прил. 2) или Преимущество (Прил. 3).

Поиск по коду выполняется с начала кода. Поиск по названию поддерживается по нескольким словам. Кликните по коду, чтобы скопировать его. Клик по бейджу приложения или «без нацрежима» фильтрует по нему.
